Teaching a model to spot a crime without ever showing it where

A frozen Kinetics-pretrained 3D CNN watches the video, a bidirectional GRU gives every moment its context, and a ranking loss learns from a single label per video. On the 290 official UCF-Crime test videos it reaches 0.844 ROC AUC.

View the code See the results

One label per video, no timestamps

UCF-Crime's training videos carry a single tag: normal, or one of the anomaly types. Nobody marked the seconds where the burglary happens. Multiple-instance learning treats each video as a bag of segments. If the bag is anomalous, at least one segment must be. If it is normal, none are.

Training then asks one question. Does the most suspicious segment of an anomalous video score higher than the most suspicious segment of a normal one? The ranking loss on the right is exactly that question, and the sliders let you feel how it behaves.

Two small extra terms, each weighted 8e-5, keep scores smooth from one segment to the next and stop the model from flagging a whole video at once.

    Read the numbers carefully

    • The AUC is computed per video. Most UCF-Crime papers report frame-level AUC, so the two are not directly comparable.
    • Validation videos come from the training set. There is no separate tuning set.
    • One seed, one run, no confidence intervals. Validation AUC is noisy, with visible dips around epochs 27 and 75.
    • The Kaggle frames are low resolution and sparsely sampled.

    Run it yourself

    The code is one script, ucf_crime_anomaly_frames.py. It indexes the frames, extracts features, trains, evaluates and writes the plots. A GPU helps for feature extraction.

    Get the code

    git clone https://github.com/Khurram32/ucf-crime-anomaly-detection-BiGRU-based-3D-CNN.git
cd ucf-crime-anomaly-detection-BiGRU-based-3D-CNN
pip install -r requirements.txt

    Get the data

    Download the frame-extracted UCF-Crime release on Kaggle and unzip it. The data is not redistributed here. It should look like Train/<Class>/<video>_<frame>.png and the same under Test/.

    Check, then run everything

    python ucf_crime_anomaly_frames.py --root /path/to/dataset --stage inspect
python ucf_crime_anomaly_frames.py --root /path/to/dataset --stage all

    Use --stage extract or --stage train to run one part. Handy flags: --epochs, --T, --clip_len, --max_clips, --train_per_class, --test_per_class, --seed.

    Reuse the trained head

    Load checkpoints/best_model.pt into GRUAnomaly, turn clip features into a bag with to_bag, and take the maximum segment score. Features must come from the same R3D-18 settings used in training. Outputs land in outputs_frames/ and cached features in features_frames/.
