One pretrained eye, one small head.

The 3D CNN never trains. Its features are computed once and cached, so the part that learns takes minutes. Pick a stage to see what happens there.

Training without frame labels

Each video is a bag of 32 segments. A ranking hinge pushes the highest-scoring segment of an anomalous video above the highest-scoring segment of a normal one, so the model has to find the moment on its own. Smoothness and sparsity terms (both 8e-5) keep the scores from jittering.

Setup

  • AdamW, lr 1e-3, weight decay 1e-3, OneCycleLR
  • Batches of 30 anomalous and 30 normal bags, 100 epochs
  • Gaussian feature noise (σ 0.01), gradient clipping at 5.0, seed 42
  • 10% of training videos held out, stratified, to pick the best checkpoint

What it catches, and what it doesn't.

Burglary, Stealing, Vandalism and Explosion are flagged roughly 75–85% of the time. Shoplifting and Robbery sit near 33–40%: short, low-motion events are hard for a clip-level motion feature.

Some anomalies are missed completely (Abuse028 stays at zero), and some fire from the first segment (Arrest007). Validation AUC is noisy, with dips near epochs 27 and 75, because the validation set is only about 160 videos.

Known limits.

  • Video-level evaluation only, so no frame-level AUC.
  • Kaggle frames are low-resolution and sparse; they are resized to 112×112 here.
  • The validation split comes from the training set. There is no separate tuning set.
  • Single seed, single run, no confidence intervals.

Run it.

A GPU helps for feature extraction. Training the head afterwards is quick.

Install

git clone https://github.com/Khurram32/ucf-crime-anomaly-detection-BiGRU-based-3D-CNN.git
cd ucf-crime-anomaly-detection-BiGRU-based-3D-CNN
pip install -r requirements.txt

Get the data

Download odins0n/ucf-crime-dataset from Kaggle and unzip it so it has Train/ and Test/ folders. The data is not redistributed here.

Extract, train, evaluate

# check the folder structure
python ucf_crime_anomaly_frames.py --root /path/to/dataset --stage inspect
# extract + train + evaluate
python ucf_crime_anomaly_frames.py --root /path/to/dataset --stage all

Use the trained head

import torch
from ucf_crime_anomaly_frames import GRUAnomaly, to_bag

ckpt = torch.load("checkpoints/best_model.pt", map_location="cpu")
model = GRUAnomaly()
model.load_state_dict(ckpt["model"])
model.eval()

# clip_feats: (n_clips, 512) R3D-18 features of one video
bag = torch.from_numpy(to_bag(clip_feats, ckpt["T"])).unsqueeze(0)
with torch.no_grad():
    segment_scores = model(bag)[0]
video_score = segment_scores.max().item()   # higher = more anomalous

Features must come from the same extractor: torchvision r3d_18, Kinetics weights, 112×112 input, 16-frame clips.
